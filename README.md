# Seti — Защищенная P2P Оверлейная Сеть (Этап 1: Сетевой Транспорт)

Проект по курсовой работе **«Защищенная оверлейная сеть передачи данных на основе пиринговых протоколов»**.

---

## 📌 Описание Этапа 1 (Сетевой транспорт и кадрирование)

На данном этапе реализована структура проекта и бинарный кадрирующий транспорт поверх TCP:

1. **Канонический 24-байтовый заголовок кадра (`HEADER_FORMAT = ">BBH16sI"`):**
   - `version` (1 byte): версия протокола (`1`)
   - `type` (1 byte): код типа сообщения
   - `flags` (2 bytes): флаги ответа/ошибок/шифрования
   - `request_id` (16 bytes): UUID сообщения
   - `payload_length` (4 bytes): длина полезной нагрузки (big-endian)
2. **Сериализация данных:** `msgpack`.
3. **Лимит payload:** Проверка `payload_length <= 65536` байт до выделения памяти.
4. **Устойчивость TCP:** Асинхронная обработка частичных и склеенных кадров.

## 🛠️ Инструкция по установке Docker

Для запуска контейнеров через Docker на Windows необходимо установить **Docker Desktop**:

1. Скачайте инсталлятор с официального сайта: [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)
2. Запустите инсталлятор и следуйте инструкциям на экране (убедитесь, что включена галочка **WSL 2**).
3. Перезагрузите компьютер при необходимости.
4. Запустите программу **Docker Desktop** из меню Пуск и дождитесь статуса *Engine running*.
